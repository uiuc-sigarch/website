* SIGARCH @ UIUC Website Source

The site is a static GitHub Pages site. Every view uses [[file:style.css][style.css]]
and [[file:site.js][site.js]] for the shared layout, theme toggle, and responsive
navigation.

** Meetings archive

Meeting materials live in the public [[https://github.com/uiuc-sigarch/meetings][meetings repository]].
The website queries that repository's public Git tree at runtime, discovers every
``.pdf`` file, groups files by their containing folder, and embeds them directly
from the repository's ``main`` branch.

#+begin_src sh
git clone https://github.com/uiuc-sigarch/website.git
#+end_src

Adding a new PDF requires only pushing it to the meetings repository in the
existing folder format. No website edit or manifest update is needed.

The PDF viewer remains browser-native, while the archive cards and controls use
the site's shared theme.
