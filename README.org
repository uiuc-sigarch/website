* SIGARCH @ UIUC Website Source

The site is a static GitHub Pages site. Every view uses [[file:style.css][style.css]]
and [[file:site.js][site.js]] for the shared layout, theme toggle, and responsive
navigation.

** Meetings archive

Meeting materials live in the public [[https://github.com/uiuc-sigarch/meetings][meetings repository]]
as a Git submodule. Clone this repository with its materials using:

#+begin_src sh
git clone --recurse-submodules https://github.com/uiuc-sigarch/website.git
#+end_src

If the site has already been cloned, initialize the submodule with:

#+begin_src sh
git submodule update --init --recursive
#+end_src

The PDF files are embedded by [[file:meetings.html][meetings.html]] using the paths in
[[file:meetings.json][meetings.json]]. After pulling new meeting materials, regenerate the
manifest and commit the updated manifest together with the submodule pointer:

#+begin_src sh
git -C meetings pull --ff-only
node scripts/update-meetings-manifest.mjs
git add meetings meetings.json
git commit -m "Update meeting materials"
#+end_src

The GitHub Actions build initializes submodules before running Jekyll so the
embedded PDFs are available in the generated site.
